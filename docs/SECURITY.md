# Security and Local Privacy Policies

TraceMap is engineered specifically for privacy-sensitive source code environments.

---

## 1. Localhost Isolation
- The FastAPI backend binds exclusively to `127.0.0.1` by default.
- It will never bind to `0.0.0.0` or expose network sockets externally.
- CORS is restricted to local frontend development origins (`http://localhost:5173`, `http://127.0.0.1:5173`).

---

## 2. Path Traversal Protection
- All requested file paths are canonicalized using `Path.resolve()`.
- Access to source code via `/api/v1/projects/{project_id}/files/{file_id}/source` strictly verifies that the requested file resides within the registered project root (`file_path.relative_to(project_root)`).
- Symbolic links outside the project root are never followed.

---

## 3. Source Code Safety & Immutability
- **Analyzed source code is never executed**: Static analysis operates strictly on concrete syntax trees (ASTs) generated by Tree-sitter without code evaluation.
- **Source code is strictly read-only**: TraceMap contains zero mutating write or delete operations targeted at user project repositories.
- Removing a project from TraceMap only drops records from `tracemap.db`.

---

## 4. Exclusion of Secrets and Sensitive Files
TraceMap automatically excludes files containing secrets from indexing:
- `.env`, `.env.local`, `.env.*`
- `.pem`, `.key`, `.crt`, `.pfx`
- Credentials, private keys, and binary caches
